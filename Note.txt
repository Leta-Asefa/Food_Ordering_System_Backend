 Options ({ new: true, runValidators: true })
new: true: By default, findByIdAndUpdate returns the document before it was updated. Setting new: true ensures that the method returns the updated document after the update operation.
runValidators: true: This tells Mongoose to run schema validation before applying the update. If any of the new data doesn't pass validation (for example, a required field is missing or a field has an incorrect type), an error will be thrown.

How State Batching Works:
1. Synchronous Updates in Event Handlers
If you have multiple setState calls inside an event handler (or similar synchronous code), React groups those updates into one batch and schedules a single re-render:
E.g
function handleClick() {
  setCount(count + 1);
  setName('New Name');
}
Here, React will batch both updates and perform only one re-render.

2. Asynchronous Updates (Outside Event Handlers)
If setState is called inside asynchronous code, like in setTimeout,setInterval,Promise , React won’t batch those updates. Instead, it will schedule separate renders for each state update:
E.g
setTimeout(() => {
  setCount(count + 1); // Triggers a re-render
  setName('New Name'); // Triggers another re-render
}, 1000);
In this case, React will trigger two separate re-renders: one after setCount and another after setName.
